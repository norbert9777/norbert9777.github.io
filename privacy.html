Privacy policy — Agent Station

Last updated: 21 October 2026

Agent Station is a personal tool operated by its owner (contact: norbert9777@inbox.lt). It is used only with the owner's own accounts.

What data the app accesses

When the owner connects a YouTube channel, the app receives an OAuth token from Google with the scopes youtube.upload (to upload videos) and youtube.readonly (to read the name and ID of the connected channel). For Instagram it receives an access token for the owner's own Instagram account. For TikTok it receives an access token through TikTok Login Kit with the scopes user.info.basic (to show the connected account's name and avatar), video.upload and video.publish (to send the owner's videos to the owner's own TikTok account).

How the data is used

The tokens are used only to upload the owner's own videos to the owner's own channels and to show which channel is connected. No other data is read.

Storage and sharing

Tokens are stored only on the owner's computer. They are not sold, shared with or transferred to anyone, and not used for advertising. Videos are sent only to the platform they are published on.

Agent Station's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deletion

Access can be revoked at any time at myaccount.google.com/permissions (Google) in Instagram settings, or in TikTok (Settings and privacy → Security → Manage app permissions). Deleting the app's data folder removes all stored tokens. To ask a question or request deletion, write to norbert9777@inbox.lt.
